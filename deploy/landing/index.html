Proto SNS

Godot 4.6 ネイティブクライアントで接続する開発用 VR SNS プロトタイプです。 Linux は Godot 版。Windows は Godot の SteamVR テスト版と、比較用の Bevy 版を配布しています。

接続先

wss://HOST/ws

クライアントの Lobby の「サーバー」欄にこの URL を入力してください。

ダウンロード

Linux (AppImage, x86_64) Windows (Godot / SteamVR test)

コード署名はしていません。Linux は Vulkan ドライバ、Windows は Vulkan または DirectX 12 のドライバが必要です。 詳細はリポジトリの docs/packaging.md を参照してください。

SteamVR では先に SteamVR を既定の OpenXR ランタイムに設定し、 zip 内の Start-SteamVR.bat を実行してください。

その他: Linux (tar.gz) / Windows Bevy 版 (比較用) / Linux Bevy 版 (比較用)
